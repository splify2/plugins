# splify2/plugins

Официальный репозиторий плагинов протоколов ядра steer (vless, hysteria2, proxy, xsteer, obfs, awg, warpbox, net1, box-connector).
Индекс `index.json` и архивы `.s2p` лежат в ветке `gh-pages` и публикуются конвейером выпуска steer; руками сюда ничего не кладётся.
Формат — [splify2/plugin-sdk](https://github.com/splify2/plugin-sdk) (`docs/index.md`).
